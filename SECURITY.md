# Security

The hooks in this repo are safety controls, so a way around one is a real bug.

## Reporting

- **Bypasses and anything sensitive:** use GitHub's private reporting
  (Security tab → *Report a vulnerability*), so it isn't public before it's fixed.
- **Low-risk gaps** (like [#1](https://github.com/erineland/claude-code-personal-assistant/issues/1)): a normal issue is fine.

Please include the hook, the tool input that got through, and what you expected.
I aim to reply within a week, and I credit reporters in the fix unless you'd rather I didn't.

## Scope

This is example code to read and adapt, not a maintained product. Fixes land on `main` only.
